# Home Portfolio - Vue.js

## 📋 Présentation

Portfolio personnel moderne et interactif présentant l'ensemble des projets réalisés et des informations personnelles. Cette application showcase met en lumière les réalisations, les compétences et les services offerts à travers une interface élégante et fluide.

## 🎯 Objectif

Créer une vitrine numérique impressionnante pour présenter les projects professionnels, attracting de potentiels collaborateurs et clients grâce à une expérience utilisateur soignée.

## 🛠️ Stack Technique

- **Framework** : Vue.js 3.5.22
- **Langage** : TypeScript
- **Build Tool** : Vite 7.1.7
- **Animations** : AOS (Animate On Scroll) 2.3.4
- **Support TypeScript** : @types/aos 3.0.7
- **Déploiement** : gh-pages 6.3.0

## 📦 Composants du Projet

### Structure du Portfolio

- **Page d'Accueil** : Introduction personnelle avec animations fluides
- **Galerie de Projets** : Présentation des réalisations majeures
- **Section Compétences** : Showcase des technologies maîtrisées
- **Animations Scroll** : Déclenchement d'animations à la lecture avec AOS
- **Design Responsive** : Adaptation à tous les appareils
- **Mode Sombre/Clair** : Support des préférences utilisateur

## 🚀 Fonctionnalités Principales
